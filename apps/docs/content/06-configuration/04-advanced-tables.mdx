## Advanced Configuration Tables

Advanced operational tables in `niki.toml`.

---

## `[goal]` Table

The goal settings are parsed, but the current goal CLI does not consume this table. Use `niki goal new "<objective>" --max <iterations>` to set the iteration limit. Goal branches are currently created as `goal/<slug>-<id>`, and state directories are selected from the detected agent environment rather than `[goal].state_dir`.

---

## `[mcp]` Table

Configure Model Context Protocol client entries with an array of tables. The current pipeline constructs an empty `McpManager`, so configured servers are **not connected or executed by `niki run`**.

```toml
[mcp]
enabled    = false # Default is false
timeout_ms = 5000
read_only  = true

[[mcp.servers]]
name    = "github"
command = "npx"
args    = ["-y", "@modelcontextprotocol/server-github"]
env     = { GITHUB_PERSONAL_ACCESS_TOKEN = "ghp_..." }
```

## `[ui]`, `[session]`, and `[compaction]`

```toml
[ui]
theme = "auto" # "auto" | "dark" | "light"

[ui.tips]
enabled = true
rotation_seconds = 30

[ui.transcript]
collapse_completed = true
expand_failures = true
show_intent_labels = true
auto_collapse_turns = false

[session]
enabled      = true
max_sessions = 50
auto_save    = true

[compaction]
enabled         = true
threshold_pct   = 80
reserved_tokens = 4096
auto_compact    = true
```
