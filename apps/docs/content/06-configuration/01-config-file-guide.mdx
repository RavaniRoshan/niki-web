## `niki.toml` Configuration Guide

NIKI reads configuration from `niki.toml` located in the root of your repository.

---

## Precedence Order

NIKI resolves configuration values using strict precedence:

1. **Run-specific CLI overrides** (for example `--planner-model` or `--backend worktree`)
2. **Supported environment variables** (for example `ANTHROPIC_API_KEY`, `OPENAI_MODEL`)
3. **Project `niki.toml`**
4. **Global `~/.config/niki/niki.toml`**
5. **Built-in defaults**

`niki auth` writes OS-keyring records, but runtime provider construction currently does not read those keyring values. Use `niki.toml` or supported environment variables for live credentials.

---

## IDE Schema Integration

Generate a local schema, then associate that file with `niki.toml` in your editor:

```bash
niki config schema
# Writes ./niki.schema.json and prints its path
```

The command writes the file; it does not only print the schema.
