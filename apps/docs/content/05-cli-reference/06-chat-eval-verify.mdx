## `chat`, `eval`, and `verify`

Interactive terminal interfaces, seeded benchmarks, and visual verification.

---

## `niki chat`

Launches a terminal user interface (TUI) powered by `ratatui` for interactive pair programming:

```bash
niki chat
```

### Supported Slash Commands

- Session: `/help`, `/clear`, `/reset`, `/compact`, `/cost`, `/context`, `/diff`, `/undo`, `/redo`, `/rewind`, `/steer`
- Configuration: `/config`, `/model`, `/theme`, `/terminal-setup`, `/status`, `/permissions`, `/plan`, `/effort`
- Workflow: `/code-review`, `/security-review`, `/fork`, `/branch`, `/rename`, `/add-dir`, `/init`, `/mcp`, `/skills`, `/voice`
- Output and metadata: `/copy`, `/export-md`, `/version`, `/usage`, `/btw`, `/loop`

`/export-md` prints a Markdown rendering into the chat log. `/memory` and `/export` are not implemented. `/loop` is recognized but reports that recurring tasks are not wired.

---

## `niki eval`

Runs NIKI against standardized or custom defect datasets to benchmark accuracy and revision efficiency:

```bash
# Run evaluation harness against dataset
niki eval --dataset evals/dataset.toml --limit 5

# Print JSON and write it under an output directory
niki eval --dataset evals/dataset.toml --format json --out .niki/eval
```

---

## `niki verify`

Captures a screenshot with `scrot`, `gnome-screenshot`, or ImageMagick when available, then appends the description, screenshot name, baseline path, and capture status to `.niki/artifacts/verify-manifest.json`. It does not compare images or compute a visual diff.

```bash
niki verify "Check that the navbar aligns properly on mobile screens" --baseline assets/baseline.png
```
