## NIKI CLI Command Overview

NIKI v0.11.0 has 30+ top-level commands organized into four logical categories:

---

## 1. Pipeline & Task Execution

- **`niki run <description>`**: Execute a coding task; the description is required.
- **`niki status [id]`**: Print task status, revision count, branch, artifact path, and report path.
- **`niki report [id]`**: Print a task's `report.md`.
- **`niki dashboard [--task <id>]`**: Generate `dashboard.html` and print its path; it does not open a browser.
- **`niki plan <description>`**: Run Planner-only plan mode and write `plan.md` without creating a branch.
- **`niki audit [id]`**: Emit a possibly partial JSON compliance bundle.
- **`niki smoke`**: Run a quick end-to-end pipeline check.
- **`niki eval`**: Replay or live-run the seeded-defect harness; `niki eval grade` records maintainer judgments.

---

## 2. Configuration, Auth & Diagnostics

- **`niki config init|schema`**: Create `niki.toml` or write `niki.schema.json`.
- **`niki init`**: Initialize configuration; `--interactive` runs the wizard and `--scan` drafts `AGENTS.md`.
- **`niki auth login|logout|status`**: Manage OS-keyring credential records.
- **`niki providers check`**: Send health checks to configured providers; bare `niki providers` is invalid because `check` is required.
- **`niki doctor`**: Inspect installation, config, credential sources, container tooling, image, and security settings.
- **`niki recommend`**: Select models from static role pairings; it can additionally display observed spend from project history.

---

## 3. Autonomous Agents, Memory & Repository Knowledge

- **`niki memory show|tags|query|preview|clear|store|recall`**: Inspect and manage project/user memory.
- **`niki goal new|list|status|pause|resume|cancel|clear|run|check|env|fork`**: Manage autonomous goals.
- **`niki research query "<query>"`**: Return raw DuckDuckGo result titles, URLs, and snippets.
- **`niki inspect`**: Print a deterministic repository manifest.
- **`niki architecture build`**: Rebuild the deterministic project knowledge base.
- **`niki index build|query`**: Build or query the advisory structural symbol index.
- **`niki skills list|candidates|promote|retire|show|diff`**: Manage versioned project skills.

---

## 4. Interactive, Integration & Verification Commands

- **`niki chat`**: Launch the interactive terminal chat surface.
- **`niki commands list|show|expand`**: Inspect built-in and project slash-command definitions.
- **`niki session list|show|checkpoints|undo|rewind`**: Inspect and rewind saved sessions.
- **`niki resume <session-id>`**: Resume an interrupted agent session from a checkpoint.
- **`niki acp`**: Run the Agent Client Protocol server over stdio.
- **`niki voice`**: Record audio and transcribe it through a configured provider.
- **`niki verify <description>`**: Capture a screenshot and append intent to `verify-manifest.json`; it does not diff images.
