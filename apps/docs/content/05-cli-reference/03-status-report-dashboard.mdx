## `status`, `report`, and `dashboard`

Inspect task executions, audit decisions, and view visual diffs.

---

## `niki status`

Prints the selected or most recent task's description, status, optional branch and verdict, revision count, artifacts directory, and report path. It does not print a current stage.

```bash
# Latest task
niki status

# Full UUID or unique short prefix
niki status 6d281d6d

# Add repository/config provenance details
niki status --with-provenance
```

---

## `niki report`

Renders the complete `report.md` decision trail for a task. Accepts full task UUIDs or unique short prefixes.

```bash
# Latest task
niki report

# View report for a specific task prefix
niki report 6d281d6d
```

---

## `niki dashboard`

Generates a standalone `dashboard.html`, prints its path, and prints a `file://` URL for you to open manually. It does not launch a browser.

```bash
# Generate for the most recent task
niki dashboard

# Generate for a specific task directory ID
niki dashboard --task 6d281d6d-3184-482a-89aa-403332152861

# Print the existing path without regenerating
niki dashboard --task 6d281d6d-3184-482a-89aa-403332152861 --path-only
```
