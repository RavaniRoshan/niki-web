## `memory` & `goal`

Long-running autonomous workflows and cross-session knowledge persistence.

---

## `niki goal`

Runs autonomous, multi-step engineering goals. The Goal Runner breaks down an objective, executes tasks sequentially, checks criteria, and halts when its drift or budget guards trip.

```bash
# Start a new autonomous goal
niki goal new "Refactor authentication system to support Passkeys and WebAuthn"

# List active and paused goals
niki goal list

# Inspect execution status and step history
niki goal status <goal-id>

# Pause the active goal; resume requires its ID
niki goal pause
niki goal resume <goal-id>
```

---

## `niki memory`

NIKI maintains a hierarchical project memory in `.niki/memory/` across runs so agents remember project architecture, conventions, and previous bug fixes.

```bash
# Query entries by an exact memory tag
niki memory query database-conventions

# Store a persistent key/value fact
niki memory store database-timestamps "Always use UTC timestamps in database models"

# Natural-language recall across user and team memory
niki memory recall "database conventions"

# View all stored tags and entries
niki memory tags
niki memory show
```
